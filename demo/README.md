# Salua — prototipo navegable

Demo interactivo de Salua: historia clínica donde el paciente es dueño de sus datos. Todo simulado en el navegador, sin backend y con datos 100% ficticios.

- **Abrir:** doble click en `index.html`, o subir esta carpeta a Vercel/Netlify tal cual.
- **Recorrido:** el panel "Guion del demo" guía los ~8 pasos (emisión → disputa → permiso → visor → denegación → vencimiento → línea de tiempo) en menos de 2 minutos.
- **Sin dependencias:** no hay npm ni build; solo HTML + CSS + JS y Google Fonts vía CDN.
