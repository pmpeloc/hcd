## 2026-10-11 · Separar corrección de objetos actuales y defaults futuros

El diagnóstico muestra permisos por defecto amplios para objetos nuevos. API #24 corrige solo los objetos actuales de Salua. Proponer una revisión posterior de ALTER DEFAULT PRIVILEGES por rol creador y esquema, con el administrador y una prueba de creación de tablas nuevas. No cambiar defaults globales sin identificar otras integraciones ni presentar esta propuesta como decisión aceptada.
